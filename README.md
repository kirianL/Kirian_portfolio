# Portfolio Maestro - Kirian Luna

Este es un portafolio personal ultra moderno, rápido y profesional construido para un Ingeniero de Software.

## 🚀 Tecnologías

- **Core**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Magic UI (Dock, Text Animate, Light Rays)
- **Animaciones**: Framer Motion
- **Iconos**: Lucide React
- **Tema**: Next Themes (Dark/Light mode)

## 🛠️ Instalación y Uso

### 1. Instalar dependencias

```bash
npm install
```

### 2. Correr en desarrollo

```bash
npm run dev
```

### 3. Construir para producción

```bash
npm run build
```

## ⚙️ Personalización de Datos

Toda la información del portafolio se encuentra centralizada en un solo archivo para facilitar su edición:

**Archivo**: `src/data/data.ts`

Puedes cambiar fácilmente:

- Nombre y título
- Descripción "Sobre mí"
- Lista de habilidades (Skills)
- Experiencia laboral
- Proyectos y stack tecnológico
- Enlaces de contacto (Email, GitHub, LinkedIn)

## ✨ Características

- **Diseño Premium**: Estética tipo "product page" con efectos de glassmorphism y blur.
- **Modo Oscuro/Claro**: Selector de tema funcional con persistencia.
- **Navegación Fluida**: Scroll suave a secciones y barra de navegación inferior estilo macOS (Dock).
- **Responsive**: Optimizado para dispositivos móviles, tablets y desktop.
- **Performance**: Construido con Vite para una carga instantánea y optimizado con Framer Motion.
- **SEO**: Estructura semántica y meta-tags configurados.
